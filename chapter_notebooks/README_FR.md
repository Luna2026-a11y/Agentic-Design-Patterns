# Agentic Design Patterns — Notebooks de code

## À propos
Notebooks de code pour le livre **« Agentic Design Patterns »** d'Antonio Gulli.
Les 21 chapitres disposent tous d'exemples de code complets et exécutables — 58 notebooks couvrant plusieurs frameworks par chapitre.

## Informations sur le livre
- **Titre** : Agentic Design Patterns : A Hands-On Guide to Building Intelligent Systems
- **Auteur** : Antonio Gulli — [LinkedIn](https://www.linkedin.com/in/searchguy/)
- **Pré-commande** : [Amazon](https://www.amazon.com/Agentic-Design-Patterns-Hands-Intelligent/dp/3032014018/)
- **Charité** : La totalité des droits d'auteur est reversée à Save the Children.

## Structure des fichiers
Convention de nommage : `Chapter_XX_Topic_(Variant).ipynb`

Chaque chapitre peut avoir plusieurs notebooks pour différentes implémentations de frameworks (Google ADK, LangChain, CrewAI, etc.).

## Pour commencer
1. Installer Jupyter : `pip install jupyter`
2. Naviguer vers ce dossier : `cd chapter_notebooks`
3. Démarrer Jupyter : `jupyter notebook`
4. Ouvrir n'importe quel notebook et commencer à apprendre !
